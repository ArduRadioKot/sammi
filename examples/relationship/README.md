# Тестовые данные анализа отношений

Импортируйте каждый CSV в отдельную таблицу через «Мои таблицы» → «Import CSV». Оба файла используют UTF‑8, запятую и заголовки, которые Sammi распознаёт автоматически.

## Локальный анализ на вымышленном клиенте

[demo-client.csv](demo-client.csv) содержит 45 строк и 45 полей для вымышленной логистической компании «Контур Северного Маяка». В наборе 12 контактов, 22 взаимодействия с июня по ноябрь 2026 года, 15 связей и 7 текстов публикаций. Столбец «Адрес» заполнен в каждой строке. Для геокодирования использованы адреса публичных зданий в Москве, Казани и Екатеринбурге, привязка контактов к этим адресам вымышлена. [Башня Федерация](https://fedtower.ru/contacts) · [ИТ-парк Казани](https://go.kzn.ru/places/it-park-1) · [Ельцин Центр](https://www.bycenter.ru/about/)

1. В мастере импорта снимите флажок «Запустить анализ и автоматически искать публикации после импорта». Откройте созданную таблицу.
2. Нажмите «Анализ отношений», снимите флажок веб-поиска и запустите обработку. Тексты публикаций уже есть в `public_text`.
3. Проверьте вертикальную карту и пять связанных таблиц. Карта должна начинаться с Лады Ветровой, а у Матвея Лунёва должны быть видны подчинённые.
4. В «Проверке источников» откройте публикацию «Сопровождение ИТ-проектов». В тексте указаны только ФИО и компания, которые совпадают у двух контактов. По сценарию автор выступления — Сергей Сотников из закупок (`c-10`). До подтверждения в «Публичных событиях» ожидается шесть записей.
5. Откройте карточку Софьи Нестеровой и проверьте рекомендацию и её источники. В отчёте также ожидается сигнал о негативной обратной связи. Сигнал о давнем касании Романа Бояринова рассчитан для запуска в конце ноября 2026 года.

Для проверки повторного импорта создавайте новую таблицу. Добавление CSV в существующую таблицу создаёт новые строки.

## Реальный веб-поиск

[live-web-search.csv](live-web-search.csv) содержит два публичных имени для запроса по Linux Foundation. Для этого сценария подключите SearXNG и оставьте включённым автоматический анализ при импорте.

В отчёте проверьте число проверенных контактов, найденные ссылки, статусы загрузки и следующую дату обновления. Выдача и доступность страниц зависят от поисковых движков и сайтов. При временном сбое используйте кнопку «Повторить обработку». Сценарий настройки описан в [README проекта](../../README.md#подключение-ollama-и-веб-поиска).
